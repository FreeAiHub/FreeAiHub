## How I work

- **Evidence over adjectives.** If something claims to be production-ready, there
  is a test suite, a pipeline and a log to show for it.
- **A demo that runs beats a feature list that does not.** One working end-to-end
  path is worth more than ten half-built modules.
- **Write down what broke.** The failure mode is usually the interesting part.
